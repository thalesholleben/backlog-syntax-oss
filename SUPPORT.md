# Support

Backlog Syntax is pre-release software with no SLA or production support commitment.

After the repository is public:

- use an issue form for reproducible bugs;
- use discussions for setup questions and implementation ideas;
- use private vulnerability reporting for security issues;
- include your operating system, Node.js and pnpm versions, command, expected result, and full sanitized error.

Do not post credentials, `.env` files, database dumps, tokens, session cookies, or personal data.
