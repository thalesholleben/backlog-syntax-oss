# Open Graph artwork

Run `pnpm og:render` from the repository root to regenerate
`apps/web/public/brand/backlog-og.png` at 1200 × 630 px.

The source background was generated with GPT Image 2 from this brief:

> Premium editorial visual for a human-and-agent backlog: deep charcoal studio, dark glass
> Kanban board, human and robotic hands placing blank task cards together, restrained acid-lime
> circuitry, quiet left side for copy, no text, no logos, no watermark.

The HTML layer owns all words, typography, domain and Syntax Lab branding so the public asset
remains exact and reproducible.
